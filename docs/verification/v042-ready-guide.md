# v0.4.2 준비 상태 동작 안내

검증일: 2026-09-17 · 버전: 0.4.2 · 빌드: 12

## 변경

- 손이 보이고 제스처 엔진이 준비 상태일 때, 커서 옆의 ‘손가락을 펴서 준비’를 ‘손동작 안내’로 바꿨다.
- 클릭·더블클릭·우클릭·스크롤·끌기 방법을 한 번에 표시한다. 드래그 잠금이 켜져 있으면 ‘집어 끌기 → 검지만 펴서 이동 → 다시 집어 놓기’, 꺼져 있으면 ‘집은 채 이동 → 손가락 놓기’를 보여준다.
- 안내 때만 폭 340pt로 펼치며 문구 높이에 맞춰 크기를 정한다. 실제 동작 상태에서는 기존 220×42pt 표시로 돌아온다.
- 마우스 사용 중, 손 상실, 끌기 잠금·놓기 확인 상태의 우선순위와 초점·클릭을 가져가지 않는 패널 설정을 유지한다.
- 제스처 판정, 카메라 처리, 메뉴 막대 상주 동작은 변경하지 않았다.

## 검증

- 기존 자동 테스트 총 121개 중 119개 통과, 사용자 원본 기록을 요구하는 2개 건너뜀, 실패 0개. `v042-tests.log`.
- 상태 표시 테스트 3개 통과. 기존 준비 문구 기대값을 갱신했고 손 상실·마우스 사용·잠금·놓기 완료의 우선순위 검사를 유지했다.
- 앱 자체의 보이지 않는 패널만 렌더링해 두 끌기 설정의 문구와 레이아웃을 눈으로 확인했다. 화면 캡처, 카메라 촬영, 실제 입력 전송은 하지 않았다.
- [잠금 켬 미리보기](v042-guide-locked.png), [잠금 끔 미리보기](v042-guide-held.png). 미리보기의 색은 화면 뒤 배경을 포함하지 않은 AppKit 렌더링 결과다.
- 설치본의 버전·서명·메뉴 막대 실행 정책과 일반 창 비표시는 `v042-install-state.json`에 기록한다. 실제 손 동작 중 안내 전환과 화면 가장자리 배치는 이번에 별도로 시험하지 않았다.

사용할 앱은 `~/Applications/AirTouch.app`이다. 업데이트 시 실행 중인 제어를 종료하고, 설치 후에는 카메라·입력을 자동으로 켜지 않는 기존 방식으로 실행한다.
