# v0.3 구현 및 검증 현황

작성일: 2026-09-15. 설치 위치: `/Users/inho/Applications/AirTouch.app`. 앱 식별자는 `dev.airtouch.mac`을 유지했다.

## 사용자가 보고한 문제

권한을 허용했지만 동작을 보지 못했고 화면이 macOS 앱처럼 느껴지지 않는다는 보고다. 목표는 실제 macOS 마우스·트랙패드 기본 조작이다. 실제 사용자의 손 좌표 기록은 아직 확보하지 못했으므로 아래 두 재현 조건이 현장 문제의 유일한 원인이라고 단정하지 않는다.

## 수정한 재현 조건

1. 30fps의 연속 정상 입력에 100ms 추론 지연을 추가하면 엔진이 계속 suspended에 머물고 move를 생성하지 않았다. 촬영 시각으로 120ms 손 손실을 판단했기 때문이다. 손 손실은 마지막 유효 결과 도착 시각으로 계산하고, 영상 노후화는 별도의 촬영 시각 기준 200ms로 유지했다. 중간 watchdog 호출을 포함한 테스트에서 수정 전 실패·수정 후 통과했다. 카메라가 실제 중단되면 눌린 버튼이 해제되는 회귀도 통과했다.
2. 검지는 잘 보이지만 접힌 중지·약지·소지의 끝 관절이 가려진 입력을 전체 무효 처리했다. 필수 추적 관절과 동작별 관절을 분리했다. 보이는 검지·손바닥으로 커서를 추적하고, 보이지 않는 손가락은 스크롤이나 펼친 손으로 확정하지 않는다. 엄지가 불확실하면 클릭을 금지하고 기존 누름은 해제한다. 가린 손가락 입력과 100ms 지연을 추출기 → 엔진 → 출력 게이트 전체로 재생해 커서 이동 의도가 도달함을 확인했다.

이는 결정론적 입력 재생 검증이며 실제 카메라 인식률이나 OS 이벤트 전달 성공을 대신하지 않는다.

## macOS UI

- SwiftUI NavigationSplitView와 기본 sidebar List, 시스템 도구 막대, 크기 조절 가능한 창
- 시스템 라이트·다크 모드를 따르는 색상과 표준 컨트롤
- Settings scene 및 ⌘, 설정 창, 표준 grouped Form
- 처음 설정을 비모달 ‘사용 준비’ 화면으로 변경해 창 닫기·종료를 막지 않음
- Mac 제어를 기본 화면으로 두고 연습과 인식 상태는 별도 페이지 제공
- 인식 상태에 유효 프레임 수·비율, 지연 제외, 처리 시간, 물리 입력 양보 횟수 표시
- 사용자가 저장하면 최근 600개 프레임의 특징 좌표·시각·엔진 상태를 로컬 JSON으로 내보냄. 영상은 저장하지 않음

Apple의 [표준 컴포넌트 및 Liquid Glass 도입 안내](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)와 [SwiftUI 새 디자인 안내](https://developer.apple.com/videos/play/wwdc2025/323/)를 참고했다. Xcode 26.4의 SDK로 빌드했으며 별도 웹 UI를 사용하지 않는다.

## 지원 입력

실제 OS 커서 이동, 왼쪽 클릭·더블클릭, 왼쪽 버튼 드래그, 세로 스크롤, 엄지·중지 핀치 후 놓기로 우클릭. 우클릭은 손 상실·관절 불확실·움직임 발생 시 취소하며, 왼쪽 버튼을 누르는 중에는 출력 게이트가 우클릭을 거부한다. 우클릭 down/up은 같은 출력 큐에서 한 쌍으로 보낸다.

가로 스크롤, 확대·축소, 회전, Mission Control/데스크톱 전환, Force Touch, 문자 입력, 여러 화면 사이 자동 이동은 이번 버전에 없다. 전체 트랙패드 기능과 동등하다고 주장하지 않는다.

## 다음 실기기 확인

Mac 제어 → 제어 시작 후 한 손 검지를 펴서 실제 OS 커서 이동을 확인한다. 이동이 없다면 인식 상태에서 프레임 수, 유효 인식 비율, 현재 안내, 지연 제외 수를 확인하고 로컬 인식 기록으로 같은 입력을 재생한다. 이어서 Finder 항목 클릭·우클릭, 창 제목 막대 드래그, 문서 스크롤, 다른 앱에서 긴급 중지, 마우스 양보를 확인한다.

외부 배포용 Developer ID 서명·공증은 포함하지 않았다. 현재 로컬 임시 서명 앱은 재빌드 이후 macOS가 권한 재허용을 요구할 수 있다.
