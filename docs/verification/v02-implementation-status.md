# v0.2 구현 및 검증 현황

작성일: 2026-09-15.

## 구현한 기능

v0.1 연습 앱에 실제 macOS 입력 전송과 첫 실행 설정을 추가했다. 전체 제어 시작 후 선택한 화면에서 이동, 클릭, 더블클릭, 드래그, 세로 스크롤을 처리한다. 이 창을 닫거나 다른 앱을 사용해도 메뉴바에서 제어를 유지한다.

첫 실행 안내는 설치 위치 → 카메라 → 손쉬운 사용 → 긴급 중지 확인 → 설정 완료 순서다. 권한은 자동으로 다시 확인한다. 권한 거부, 제한, 재허용, 설정 목록에 앱이 없는 경우와 전역 키 등록 충돌을 안내한다. 설정 완료와 실제 제어 시작은 별도 동작이다.

출력 직전에는 세션 번호, 관절 유효성, 프레임 시간, 입력 전송 권한을 검사한다. 출력 큐는 UI·추론 큐와 분리했다. 마우스/트랙패드를 직접 사용하면 소유한 버튼을 해제하고 1.5초 동안 양보한 후 현재 커서 위치를 새 기준으로 삼는다. 직접 누른 마우스 버튼이 남아 있을 때에는 제어를 재개하지 않는다.

전체 제어판의 앱 식별자는 `dev.airtouch.mac`이다. 이전 연습판 `dev.airtouch.practice`와 권한 등록을 분리했다. 설치 앱 폴더의 경로를 유지하면서 Contents를 교체하고, 이전 Contents는 LaunchServices가 앱으로 발견하지 않는 `.airtouch-backup` 폴더에 보관한다.

## 테스트가 검증하는 내용

- 짧은 핀치 무시, 반복 down 방지, 클릭·드래그의 균형 잡힌 down/up
- 스크롤과 누름 충돌, 제스처 전환 시 오래된 대기 시간 제거
- 손 상실, 영상 정지, 정지 후 들어오는 이전 세션 입력 폐기
- 상대 좌표 재설정, 미세 이동 누적, 화면 경계에서 반대 방향으로 복귀
- 출력 권한 철회 후 해제·중단, 긴급 중지를 지연 프레임이 되돌리지 못함
- 유효한 손 없이 시작만 한 세션에서 누름을 거부함
- 음수 화면 원점, Retina 배율을 중복 적용하지 않는 좌표 변환
- 출력 큐 watchdog에 의한 독립 해제

## 실제 사용 전 확인할 내용

카메라와 손쉬운 사용은 macOS의 권한 화면에서 사용자가 허용한다. 현재 설치 앱에서 모두 허용된 뒤 설정 완료 → 전체 제어 시작을 누른다. 밝은 환경에서 한 손 전체를 보여주고 검지를 편다.

링크 클릭, 창 드래그, 문서 스크롤을 실제 앱에서 수행한다. 화면 방향과 스크롤 방향을 확인하고 필요하면 설정에서 스크롤을 반전한다. 마우스로 움직였을 때 제어가 양보되는지, 손을 내렸다 다시 들었을 때 커서가 튀지 않는지 확인한다. 다른 앱에서 ⌃⌥⌘Space가 제어와 카메라를 멈추는지도 실제 키보드로 확인한다.

정상 엔진의 손 상실 기준은 120ms, 영상 만료는 200ms다. 출력 큐의 추가 watchdog은 영상 갱신 250ms 또는 누른 상태의 유효 손 200ms 초과를 기준으로 동작한다. 스케줄링과 OS 상태에 따른 실제 반응 시간은 실측이 필요하다. 권한이 철회된 뒤의 해제 이벤트 전송과 프로세스 강제 종료 때의 정리 실행을 보장하지 않는다.

화면 잠금은 잠금 알림, 사용자 세션 비활성화, 화면 잠자기 알림에 대응한다. macOS 버전별 잠금·복귀 동작은 추가 실기기 검증 항목이다. 외부 배포용 Developer ID 서명·공증은 이번 로컬 설치에 포함하지 않았다.
