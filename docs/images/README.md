# 실제 앱 스크린샷

2026-09-19에 설치된 **AirTouch v0.4.5 (build 15)**의 설정 창을 CUA로 직접 캡처했다. 테스트 렌더링이나 합성 화면이 아니다.

| 파일 | 촬영 당시 화면과 설정 |
| --- | --- |
| [settings-pointer.png](settings-pointer.png) | 포인터 및 스크롤 탭의 화면에 보이는 상단 영역. 개인 보정 적용 중, 편안하게 모드, 이동 속도 2.0×, 움직임 보정 균형, 드래그 잠금과 커서 상태 표시 켜짐. |
| [settings-general.png](settings-general.png) | 일반 탭. 카메라와 손쉬운 사용 권한 허용 상태, 긴급 중지 단축키와 개인정보 안내. |

두 파일은 촬영 당시의 설정 상태이며 기본값을 뜻하지 않는다. 카메라 영상은 포함하지 않았다. 이 캡처만으로 실제 손 인식이나 macOS 입력의 성공을 검증한 것은 아니다.

README의 보정·집기·커서 안내 이미지는 `docs/verification/`의 별도 UI 렌더링 검증 결과로 구분한다.
