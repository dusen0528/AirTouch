# 등록용 초안 · ko-KR

공개·제출되지 않은 문구입니다.

**이름:** AirTouch · 손동작 마우스

**부제:** MacBook 카메라로 커서·클릭·스크롤

**키워드:** 핸즈프리,제스처,포인터,드래그,터치리스,비접촉

MacBook 내장 카메라로 손동작을 읽어 Mac의 커서를 움직여보세요. AirTouch는 검지 이동과 손가락 집기를 마우스 이동, 클릭, 드래그, 세로 스크롤로 연결합니다.

내 손에 맞춰 시작
약 30초 동안 편한 이동 범위와 손 떨림, 집는 간격을 보정합니다. 결과를 확인하고 적용한 뒤에도 다시 맞추거나 초기화할 수 있습니다.

계속 집고 있지 않아도 되는 드래그
엄지와 검지를 모아 끌기를 시작하고, 손가락을 풀어 이동하세요. 다시 집으면 놓습니다. 기존처럼 계속 집는 방식도 선택할 수 있습니다.

커서 옆에서 확인하는 상태
현재 이동·클릭 준비·끌기 잠금·손 인식 상태를 커서 근처에서 확인합니다.

필요할 때 바로 중지
마우스나 트랙패드를 직접 사용하면 손동작 제어가 잠시 멈춥니다. 메뉴 막대 또는 ⌃⌥⌘Space로 제어와 카메라를 중지할 수 있습니다.

사용 조건
• macOS 14 이상과 MacBook 내장 카메라가 필요합니다.
• 카메라와 손쉬운 사용 권한을 허용해야 Mac을 제어할 수 있습니다.
• 한 번에 한 손으로 선택한 한 화면을 제어합니다.
• 인식과 반응은 조명, 손 위치, 카메라 상태에 영향을 받습니다.
• 확대·축소, 가로 스크롤, 화면 사이 자동 이동은 지원하지 않습니다.

카메라 영상은 이 Mac 안에서 처리하며 저장하거나 전송하지 않습니다. 개인 보정은 보정값만 저장합니다. 인식 기록을 직접 내보내면 손 좌표와 처리 시간이 로컬 JSON에 포함됩니다.

## 제출 전 확인

- Mac App Store 배포 적합성 및 실제 제출용 빌드 검증
- 실제 손동작 성공과 스크린샷 확인
- 지원 및 개인정보 처리방침 공개 URL
- App Store Connect 앱 등록과 실제 메타데이터 입력 확인
