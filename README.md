# AirTouch

MacBook 내장 카메라로 macOS의 커서 이동, 클릭, 더블클릭, 우클릭, 드래그, 세로 스크롤을 수행하는 메뉴바 앱.

**v0.3.2: 기본 macOS 창·사이드바·도구 막대·설정 창으로 UI를 교체하고, 커서 활성화, 움직임 보정 지연, 자세 전환 시 멈춤을 개선했다.** 실제 손동작의 인식률·피로도·앱별 입력 반응은 별도 실기기 검증 항목이다. 합성 데모 결과를 카메라 성능으로 표시하지 않는다.

## 설치와 실행

```bash
./scripts/install-app.sh
```

기본 설치 위치는 `~/Applications/AirTouch.app`이다. 기존 AirTouch가 있으면 종료 후 다시 실행한다. 이전 Contents는 설치 중에만 임시 보관하고, 새 앱의 서명 검증과 설치 등록이 성공하면 정리한다. 실패하면 이전 Contents를 복원한다. 다른 앱은 덮어쓰지 않는다.

직접 빌드해 실행할 수도 있다.

```bash
./scripts/build-app.sh
open .build/packaging/AirTouch.app
```

직접 빌드는 `.build/packaging/AirTouch.app`에 임시 패키지를 만든다. 일반 사용은 설치 스크립트를 이용하면 설치 후 이 패키지가 삭제되어 실행 앱이 하나만 남는다.

개발 폴더에서 실행하면 첫 안내의 **설치하고 다시 열기** 버튼으로 홈 폴더의 응용 프로그램에 복사할 수 있다. 권한을 허용하기 전에 사용할 설치 위치를 정하는 것을 권장한다.

## 첫 실행

앱을 처음 열면 사용 준비 화면이 자동으로 나온다.

1. **설치 위치**를 확인한다.
2. **카메라 허용**을 누르고 macOS 요청에서 허용한다. 거부한 경우 설정으로 안내한다.
3. **손쉬운 사용 설정 열기**를 누른다. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 **AirTouch**를 켠다.
4. 목록에 없다면 **+**로 현재 실행 중인 AirTouch 앱을 추가한다. 사용 준비 화면의 Finder 버튼으로 설치 앱을 찾을 수 있다.
5. **⌃⌥⌘Space**를 눌러 긴급 중지를 확인한다. 다른 앱을 사용 중이어도 작동한다.
6. 권한 상태가 갱신되면 **완료 → Mac 제어 → 제어 시작**을 누른다.

설정에서 돌아오면 앱이 권한을 자동으로 재확인한다. 앱이 카메라·손쉬운 사용 권한을 스스로 허용하는 방식은 사용하지 않는다. 허용은 macOS의 권한 화면에서 사용자가 수행한다. 이미 켜져 있지만 허용되지 않는다면 AirTouch를 완전히 종료하고 손쉬운 사용 목록에서 기존 AirTouch를 제거한 뒤 현재 설치 앱을 다시 추가한다. 서명이 다른 이전 등록은 토글만으로 복구되지 않을 수 있다. 이번 개발 인증서 전환에서 macOS 로그의 code requirement 불일치가 확인됐다.

전역 중지 단축키가 다른 AirTouch 인스턴스와 충돌하면 전체 제어 시작을 막고 재등록 버튼을 표시한다. 카메라 또는 입력 전송 권한이 없을 때에도 실제 제어를 시작하지 않는다. 설정 완료 여부와 관계없이 매 실행 시 실제 권한 상태를 검사한다.

## macOS 기본 화면

사이드바에서 Mac 제어, 손동작 연습, 사용 준비, 인식 상태로 이동한다. 처음 설정은 일반 화면으로 표시해 창 닫기와 종료를 막지 않는다. ⌘, 또는 도구 막대의 설정 버튼에서 이동 속도·움직임 보정·스크롤 방향을 바꾼다.

## 조작

| 동작 | 결과 |
| --- | --- |
| 검지만 0.35초 이상 펴기 | 현재 커서 위치에서 제어 시작 |
| 검지 이동 | 커서 상대 이동 |
| 엄지·검지 모았다 놓기 | 클릭 |
| 같은 위치에서 핀치 두 번 | OS 더블클릭 시간 범위 안에서 더블클릭 |
| 엄지·중지 모았다 놓기 | 우클릭 (손이 움직이거나 가려지면 취소) |
| 핀치 유지 + 손 이동 | 왼쪽 버튼 드래그 |
| 검지·중지 펴고 상하 이동 | 세로 스크롤 |
| 손바닥 펴기 / 손 내리기 | 쉬기, 눌린 입력 해제 |
| 마우스·트랙패드 직접 사용 | 일시 양보. 멈춘 뒤 1.5초 후 검지 자세로 재개 |
| ⌃⌥⌘Space | 어느 앱에서든 제어 중지 및 카메라 끄기 |
| 메뉴바 AirTouch → 전체 제어 중지 | 제어 중지 |

전체 제어 중에는 다른 앱으로 이동하거나 설정 창을 닫아도 메뉴바에서 제어를 유지한다. 앱을 종료하면 제어도 종료한다. 재실행 시에는 자동으로 입력을 시작하지 않는다.

제어할 화면은 중지 상태에서 선택한다. 외부 화면의 원점과 해상도는 CoreGraphics 좌표로 처리하며, 화면 구성이 바뀌면 제어를 중지한다. 현재 버전은 선택한 한 화면을 제어하며 화면 사이를 자동으로 넘나들지는 않는다.

## 연습과 진단

**연습** 모드는 앱 내부 목표 클릭·상자 드래그·스크롤 화면에서만 동작한다. **데모 재생**은 카메라 없이 합성 좌표 660프레임으로 같은 입력 엔진을 재생한다. 시스템 입력은 보내지 않는다.

```bash
./scripts/test.sh

# 앱을 완전히 종료한 뒤 실행
open .build/packaging/AirTouch.app --args --demo --demo-report /tmp/airtouch-demo.json
```

**인식 상태 → 인식 기록 저장**은 로컬 JSON으로 상태 전이, 입력 요청 수, 권한 상태, 처리 시간, 최근 600프레임과 마지막 동작 1,800프레임의 손 좌표·타이밍을 저장한다. 기록에는 유효 손 인식 비율, 지연으로 제외한 프레임 수, 물리 마우스에 양보한 횟수도 포함된다. 영상은 저장하지 않는다. 카메라 처리 시간은 캡처부터 Vision 완료까지의 값이며 전체 체감 지연과 다르다. 시스템 입력 요청 수는 대상 앱의 처리 성공 횟수를 뜻하지 않는다.

## 구현과 범위

- SwiftUI NavigationSplitView, 시스템 도구 막대, Settings scene(⌘,), 크기 조절, 시스템 라이트·다크 모드
- AppKit 메뉴바 앱, AVFoundation, Apple Vision
- 손 크기 정규화, 관절 각도 기반 자세, 속도에 따라 반응하는 One Euro Filter, 상대 커서
- 120ms 이내의 일시적인 자세 불확실성에서 재활성화 대기를 생략하고, 스크롤에서 검지 이동으로 바로 복귀
- 앱의 카메라 반응 효과를 제외하도록 Apple SDK 설정 적용
- CoreGraphics 마우스·스크롤 전송, 클릭 횟수 필드, 세션별 버튼 소유권
- 추론·UI와 분리한 출력 큐 및 watchdog, 권한 철회·오래된 입력 차단
- Carbon 전역 중지 단축키, 합성 입력과 직접 마우스 입력 구분
- 첫 실행 안내, 권한 거부·재허용 안내, 설치·설정 저장·재실행

트랙패드 동작 중 현재 제공하는 범위는 커서 이동, 클릭·더블클릭·우클릭, 드래그, 세로 스크롤이다. 가로 스크롤, 확대·축소, 회전, Mission Control/데스크톱 전환, Force Touch, 문자 입력, 브라우저 뒤로/앞으로, 여러 화면 간 자동 전환은 아직 제공하지 않는다. 화면 잠금·잠자기·강제 종료와 실제 앱별 드래그 반응은 지원 기기에서 추가 확인해야 한다.

macOS 14 이상과 빌드용 Xcode가 필요하다. 외부 패키지 의존성은 없다. 빌드 스크립트는 해당 프로세스에서만 설치된 Xcode 경로를 사용하며 시스템 설정은 바꾸지 않는다.

현재 설치본은 이 Mac의 Apple Development 인증서로 서명했다. 빌드 스크립트는 단일 개발 인증서가 있으면 자동 사용하며, 여러 개면 AIRTOUCH_SIGN_IDENTITY를 지정한다. 인증서가 없는 환경에서만 임시 서명을 사용한다. 이전 임시 서명에서 개발 서명으로 처음 바뀔 때는 권한을 다시 허용해야 할 수 있다. 이후 같은 인증서를 사용하는 업데이트는 동일한 서명 요구사항을 유지한다. 외부 배포용 Developer ID 서명과 공증에는 소유자의 배포 인증서가 필요하며 이번 로컬 설치에는 포함하지 않았다.
